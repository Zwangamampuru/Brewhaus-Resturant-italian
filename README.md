# Brewhause Restaurant 🍝

A single-page Italian restaurant landing site built with **plain HTML and CSS** — no frameworks, no build tools. Features a hero, menu, about section, reservation call-to-action, and footer with hours and location.

> *"A taste of Italy, one bite at a time."*

## ✨ Features

- **Semantic HTML landmarks** — `<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`
- **Single `<h1>`** for accessibility and SEO
- **Responsive layout** using real **Flexbox** (navigation) and **CSS Grid** (menu, about, footer)
- **Global `box-sizing: border-box`** for predictable sizing
- **CSS custom properties** (`--deep-forest`, `--golden`, `--cream`, etc.) for a consistent palette
- **Bouncing reservation CTA** button (1s up-and-down animation)
- **Interactive nav** — links turn green on hover, red once visited
- **No horizontal scroll** on phone, tablet, or desktop
